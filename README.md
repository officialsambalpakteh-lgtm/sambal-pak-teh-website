# Sambal Petai Pak Teh Website

Website rasmi untuk jenama **Sambal Petai Pak Teh**.

Website ini dibangunkan sebagai platform utama untuk memperkenalkan jenama, produk, konsep perniagaan dan memudahkan pelanggan mendapatkan maklumat serta membuat pertanyaan produk.

---

## 📌 Tentang Projek

**Sambal Petai Pak Teh** merupakan jenama sambal homemade premium yang mengetengahkan rasa tradisional asli dengan konsep:

- Produk keluaran terhad (Limited Stock)
- Ready Stock sahaja
- Kualiti dan rasa sebagai keutamaan
- Pembelian melalui platform digital

Website ini berfungsi sebagai:

✅ Pusat informasi produk  
✅ Platform branding syarikat  
✅ Rujukan pelanggan  
✅ Penghubung ke TikTok Shop  
✅ Sistem pertanyaan pelanggan melalui WhatsApp

---

# 🌐 Struktur Website

Website mempunyai beberapa halaman utama:

## 1. Home (index.html)

Paparan utama jenama:

- Pengenalan Sambal Petai Pak Teh
- Konsep produk
- Keistimewaan sambal
- Call-to-action pelanggan

---

## 2. Tentang Kami (about.html)

Mengandungi:

- Kisah dan identiti jenama
- Konsep penghasilan produk
- Nilai dan visi perniagaan

---

## 3. Produk (products.html)

Memaparkan:

- Produk utama Sambal Petai Pak Teh
- Maklumat produk
- Status stok
- Butang pertanyaan produk
- Butang pembelian TikTok Shop

---

## 4. Galeri (gallery.html)

Status semasa:

**COMING SOON**

Akan dikemaskini dengan:

- Gambar produk sebenar
- Packaging
- Proses penyediaan
- Aktiviti jenama

---

## 5. Hubungi Kami (contact.html)

Fungsi:

Pelanggan boleh isi:

- Nama
- Nombor WhatsApp
- Pertanyaan produk

Pasukan Sambal Petai Pak Teh akan menghubungi pelanggan semula.
